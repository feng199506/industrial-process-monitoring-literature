# 工业过程监控文献库

本目录收集工业过程及工业过程监控相关的研究论文、综述、大学课程讲义、教科书、专著和参考书。只做文献收集与整理：不含数据集、模型权重，没有运行实验、训练或部署。这是范围检索，不宣称穷尽。

- 检索与整理日期：2026-10-29（UTC）。近三年窗口：首次公开日期 2023-10-29 至 2026-10-29。
- 计数规则：只有完整原文已保存到本地、且通过核验的资料才计数。失败、待核验、重复版本和部分正文都不计数，登记在 `download_failures_cn.csv`。
- 本目录是独立文献库，没有修改此前的三个文献库（时间序列、机器学习与深度学习、大模型多模态）。从机器学习库复制的 9 本书和 3 篇论文都标为“已有复用（跨库重复）”。

## 3. 领域字段与依据

- 行业、生产过程、任务、连续/批次、方法类别、机理信息使用、数据来源、数据集、是否公开、代码、工况、故障类型、标签条件、在线/离线、切分方式、是否用故障测试数据调参、评测指标、点调整：这些字段依据摘要填写（“字段依据”列）。摘要没有说明的写“待全文核实”，没有推断。
- “全文关键词自动检出（未人工核读）”列来自对全文的关键词扫描，内容包括：
  - 基准或数据集名称，TE 修订版线索（Bathelt、Reinartz、Rieth 等）
  - 指标词
  - 是否出现点调整
  - 随机划分相关表述（附上下文片段）
  - 代码链接

  这些只是线索，不代表人工核实。
- 基准仿真数据（TE、青霉素仿真、BSM 等）一律不标为真实工厂数据。随机划分相邻窗口得到的结果，不能当作未来泛化证据。是否用故障测试数据调参或设阈值，几乎所有条目都需要全文核实。
- 本库不对任何模型作“最优”或“可直接部署”的判断。

## 5. 优先阅读与阅读路线

见 [reading_map_cn.md](reading_map_cn.md)。阅读路线分 10 个阶段：统计基础 → 控制图与 SPC → MSPM 与潜变量 → 过程动态、辨识与状态估计 → 检测与评测方法 → 诊断与根因 → 多工况与迁移 → 质量、软测量与批次 → 机理融合与数字孪生 → 深度方法与工业大模型。每类前 10 份都附有理由。

## 6. 访问限制与处理（均未绕过）

- **MDPI、ScienceDirect、Wiley、Taylor & Francis、SAGE、AIP、部分 EDP**：对本机返回 403。这些出版社的论文只在 PMC 官方开放获取数据集、arXiv 或作者存档有合法副本时才收录。
- **HAL**：全文地址启用了反机器人验证。约 53 条 HAL 来源的条目因此下载失败，由备选递补。
- **OpenAlex、Semantic Scholar**：本机 IP 的免费额度耗尽或被限流，没有使用，也没有代用户申请 API key。
- **DOAB、OAPEN**：对本机 IP 返回 403。
- **其他失败**：De Gruyter 和 MIT Press 的部分开放获取书落地页触发验证或拒绝访问；Linköping 诊断教材地址 404；Basseville《Detection of Abrupt Changes》作者站 403。
- **人工否决**：Dagstuhl 的两个链接返回的是同卷中的另一篇论文，予以否决，不计数。

## 7. 未完成类别、疑点与具体缺口

- **02（缺 11）**：近三年潜变量过程监控论文主要发表在 IEEE Transactions 或 Elsevier 期刊上，没有合法开放全文。可下载的只有 IEEE Access、PMC 和 arXiv 来源。
- **03（缺 4）、04（缺 5）、06（缺 8）**：备选已经用完；HAL 反机器人验证使约 25 条主列表条目失败。06 的动态建模和工况过渡子方向偏薄。
- **10**：约 50 篇确实与工业过程直接相关，但后段（智能体式过程控制、制造业 LLM、在工业数据上评测的通用基础模型）相关性较弱。只有约 12 篇使用真实或混合工业数据，少样本方向只有 2 篇。
- **11**：没有找到可合法下载的 TE 修订版或扩展数据集论文；类内约 40% 是基础方法类的时间序列评测论文。
- **12**：造纸与水泥只有 2 篇，半导体 4 篇。
- **13、14**：缺口约 25 本/个。公开的完整过程监控课程讲义很少，一批开放获取图书目录或出版社屏蔽本机。Stanford AA203 课程页上有 1 个讲次链接 404，整包不计数。
- **版本疑点**：
  - 03-004：arXiv v1 PDF 的题名与当前元数据题名不同，已人工核对，属于同一研究。
  - 08-023：Crossref 的印刷日期是 2027 年，首次公开以在线日期为准。
  - 部分 IEEE Access 论文的首次公开日期用 DOI 注册日近似。
- **字段完整性**：243 篇的数据来源仍是“待全文核实”。少数条目没有摘要，依据标为“题录（摘要缺失）”。

## 8. 续跑

宿主机没有 pip。pypdf 5.1.0 的 wheel 已解压在 `/root/.cache/ipm_lit/pylib`，下载暂存目录是 `/root/.cache/ipm_lit/staging`（都在本目录之外）。

```bash
cd /root/industrial_process_monitoring_literature
python3 -I scripts/discover_en.py run NN                 # 执行 seeds/queries_NN_en.json 中新增的检索式（已执行的会跳过）
python3 -I scripts/pmcmap_en.py                          # 新 DOI 映射 PMCID
python3 -I scripts/screen_en.py NN                       # 查看未认领、有合法全文渠道的候选
python3 -I scripts/seedcheck_en.py NN                    # 在 seeds/NN_*_seed_cn.json 追加条目后校验
python3 -I scripts/papers_en.py resolve NN && python3 -I scripts/papers_en.py download NN [--retry-failed]
python3 -I scripts/materials_en.py fetch 13|14 [--retry-failed]
python3 -I scripts/fields_en.py && python3 -I scripts/build_catalog_en.py
python3 -I scripts/build_searchlog_en.py && python3 -I scripts/build_reading_map_en.py
sha256sum -c checksums_en.sha256
```

下载脚本是断点续跑的：已核验的条目会跳过；不会覆盖哈希不同的同名文件；同一文献只在最早认领它的类别计数。
